# GharMap

A home inventory app built around a spatial map of the home: home → room → unit → compartment → item.
This is **Phase 0**: a browser-only web app (no backend, no login, no sync) to test whether the family keeps
entering and finding things. See [docs/build-plan.md](docs/build-plan.md).

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:5173. The dev server also listens on your LAN, so a phone on the same Wi-Fi can open
`http://<your-mac-ip>:5173`.

| Command | What it does |
| --- | --- |
| `npm run dev` | Vite dev server for the web app |
| `npm test` | Unit tests for `packages/core` (Vitest) |
| `npm run e2e` | End-to-end tests (Playwright, in installed Chrome) at phone and desktop sizes |
| `npm run typecheck` | TypeScript: core, web and e2e |
| `npm run build` | Production build to `apps/web/dist` |

## Layout

```
packages/core   Plain TypeScript, no UI: types, demo data, home tree, search, edits, backup format.
                The Phase 1 Expo app reuses it as is.
apps/web        Phase 0 React + Vite UI (six screens: map, space, item, search, quick add, settings).
                Phone layout with a bottom tab bar; from 900 px wide, a desktop layout with a sidebar.
apps/web/e2e    Playwright suite; every test runs as "mobile" (Pixel 7) and "desktop" (1280×800).
design/         The original clickable mockup (Claude Design canvas format; reference only).
docs/           Build plan, risk review notes, and the planning chats this came from.
```

## Phase 0 status

Done: map with tap-to-zoom, space and item screens, search with path highlight on the map, timed quick add
(Gate 0 measure), move with history, add sections, JSON export/import, reset to demo data.
Data persists in `localStorage`.

Not yet (from the plan): SQLite WASM in a worker (OPFS) with FTS5 search, PWA install/offline,
S3 + CloudFront deploy.

## Note on Google Drive

This folder lives in Google Drive. `node_modules/` and `dist/` are regenerated by `npm install` / `npm run build`
and are safe to delete if Drive sync gets slow or the disk fills up.
